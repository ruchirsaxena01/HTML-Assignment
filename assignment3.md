<h3> Common Terminal Commands </h3>

1. "pwd" — Present Working Directory

<p>It shows the complete location of the directory in which we are currently working.</p>

2. "dir" — Display Directory Contents

<p> It provides a list of the files and subfolders present in the current location. </p>

3. "cd foldername" — Enter a Directory

<p> This command helps us open or move into another folder. </p>

Example: "cd Documents"

4. "cd .." — Return to the Previous Level

<p> It takes us one step back to the folder containing the current directory. </p>

5. "cd ~" — Open the User's Home Folder

<p> This command is used to reach the home directory of the current user. </p>

6. "mkdir foldername" — Make a Directory

<p> It allows us to create a new folder at the current location. </p>

Example: "mkdir Web-Development"

7. "cls" — Clear Screen

<p> It removes the previously displayed text from the terminal screen in Windows Command Prompt or PowerShell. </p>
