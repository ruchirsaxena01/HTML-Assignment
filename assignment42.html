Mobile Responsiveness Audit & Fixes

Documented by Ruchir Saxena · Invertis University, Bareilly

Issue 1: Hardcoded Element Widths

DEFECT Fixed widths like width: 900px; cause severe horizontal scroll on mobile devices.

FIX Replaced with max-width: 900px; width: 100%; margin: 0 auto; allowing fluid contraction.

Issue 2: Unconstrained Media / Images

DEFECT Images without fluid styling overflow their parent columns.

FIX Enforced the standard rule: img { max-width: 100%; height: auto; }.

Issue 3: Desktop Viewport Meta Tag Absence

DEFECT Without <meta name="viewport">, mobile browsers render desktop-sized pages at 980px zoom.

FIX Included <meta name="viewport" content="width=device-width, initial-scale=1.0"> on every document.
