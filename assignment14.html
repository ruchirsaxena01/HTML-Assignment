Program Profile: Bachelor of Computer Applications (AI)

Duration: August 2026 to June 2029 | Total Credits: 155

Semester-by-Semester Progression

  1. Semester I: HTML & CSS, Programming in Java, Mathematics, Data Analytics (22 Credits)
  2. Semester II: Linux Shell Scripting, Python Programming, Power BI, Operating Systems (29 Credits)
  3. Semester III: DBMS, Data Structures, Computer Networks, Machine Learning (26 Credits)
  4. Semester IV: Introduction to AI, Sensor Technology, Responsive Web Design (30 Credits)
  5. Semester V & VI: Advanced AI Electives, Capstone Industry Project, and Internship (48 Credits)

Campus Highlights

  • Location: Bareilly-Lucknow Highway, NH-24
  • Labs: Advanced Computing Labs equipped with modern development tools
  • Activities: Annual Tech Fest, Hackathons, and Coding Clubs
