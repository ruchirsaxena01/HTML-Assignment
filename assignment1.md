<h2>Write a one-paragraph explanation of what happens between typing a URL and seeing the page.</h2>
When you type a URL into a web browser and press Enter, the browser first checks the URL and looks for the website’s IP address using DNS (Domain Name System). Then, it establishes a connection with the web server using TCP and, for HTTPS websites, secures the connection using TLS encryption. The browser sends an HTTP request to the server, which processes the request and sends back a response containing resources such as HTML, CSS, JavaScript, and images. The browser then reads the HTML to create the page structure, applies CSS to style the page, and executes JavaScript to add interactivity. Finally, it renders all the elements on the screen, allowing you to see and interact with the webpage.
