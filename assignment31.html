Flexbox Menu Bar Demonstration

This navigation bar leverages Flexbox alignment utilities:

  • display: flex; with justify-content: space-between; distributes the logo, menu links, and action button cleanly.
  • align-items: center; vertically centers all items across different font sizes and button heights.
  • gap: 1.5rem; provides consistent spacing between list elements without fragile margin hacks.
